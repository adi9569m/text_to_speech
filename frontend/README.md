# VoiceFlow — Frontend

Modern web user interface for VoiceFlow, built with React 19, Vite, and Tailwind CSS.

## Features

- **Studio View**: Clean text editor, document drag-and-drop import (.txt, .pdf, .docx), voice audition sample player, and speech parameter sliders.
- **Audio Workstation**: Custom waveform player, speed controls, dual-format download (MP3/WAV), and shareable links.
- **History & Library**: User-scoped speech history, search, favorites, and quick script reloading.
- **Analytics Dashboard**: Real-time stats on character counts, word counts, and voice usage distribution.
- **Responsive & Accessible**: Light theme with clean typography and keyboard navigation support.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
